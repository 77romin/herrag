# 스토리팩 대화 및 결말 검증

검증일: 2026-09-04. 실제 설정된 AI API와 기존 스토리팩 캐시를 사용했다. 이 기록은 소규모 기능·대화 점검이며 RAGAS 점수나 통계적 정확도 평가가 아니다.

## 범위

- 최초: 기본 5개 팩에서 연속 대화 16건과 독립 결말 선택 5건.
- 재검사: 교토·베네치아·라디오·제주에서 문제 사례 중심 대화 9건과 결말 선택 4건.
- 추가: 교토 동의와 제주 대화 연결 등 문제 사례 집중 재검사.
- 각 입력은 API 실패 여부뿐 아니라 답변 내용, 현재 장면, 종료 여부를 확인했다.
- 결말 검사는 마지막 장면과 미응답 질문을 직접 구성한 독립 검사다. 모든 분기를 처음부터 끝까지 플레이한 것은 아니다.

## 발견한 문제와 수정

| 문제 | 수정 |
| --- | --- |
| 설명을 버리고 고정 확인 질문만 표시 | 응답 전체를 고정 질문으로 덮어쓰는 처리 제거. 일반 답변은 진행 조건과 분리 |
| 아직 미응답인 질문도 반복으로 판정 | 이미 답한 조건에 연결된 질문만 반복 검사 |
| 공통 질문 ID를 완료 조건으로 잘못 사용 | 실제 경로의 조건 ID를 생성 스키마 enum과 별도 목록으로 제한 |
| 질문의 장면 번호 등 보조 정보 때문에 정상 응답 실패 | 검증 가능한 장면 번호 보정, 일반 질문은 목표 질문과 분리 |
| 장소 충돌 판정의 원문 인용 부정확 | 검증된 상태와 초안을 주어 최대 한 번 수정 |
| 다음 장면의 고민을 설명하지 않고 의견 질문 | 도입 문장과 장면 번호를 함께 생성·검증. 도입의 의미 자체는 수동 검토 필요 |
| 짧은 동의에 낮은 추론을 적용했을 때 진행 판단 누락 | 선택 질문의 응답은 기본 추론으로 처리 |

정상적인 질문 응답에는 추가 호출이 없다. 상태·인용·반복·도입 오류가 있으면 최대 한 번 수정 호출한다. 수정 후에도 불일치하면 게임 상태를 변경하지 않고 오류를 반환한다. 따라서 모든 실패를 없앴다고 볼 수 없으며, 수정 호출은 응답 시간을 늘릴 수 있다.

## 팩별 관찰

| 팩 | 입력 유형 | 관찰 |
| --- | --- | --- |
| 교토 | 어떻게 알았는지 질문, 사과, 반환, 짧은 동의 | 스트랩 차이를 설명하고 사과에 반응. 짧은 동의와 다음 고민 도입에서 추가 보완 필요가 확인되어 별도 재검사 |
| 베네치아 | 동창 인정, 한강대교 이동 제안, 동행 동의 | 동창 인정과 동행을 구분. 충돌 인용 실패를 발견했고 재검사에서 충돌 안내·장면 유지 확인 |
| 제주 | 말을 건 이유, 함께 정리하겠다는 동의, 근황 질문 | 초기 보조 정보·반복 검사에서 실패. 수정 후 이유와 근황에 답하고 대화를 이어감 |
| 라디오 | 방송 종료 이유, 별명 지정, 침묵 선택 | 초기 반복 검사 실패 수정. 별명 반영과 침묵에 따른 진행 확인. 종료 사유가 원문 '숨겨진 사실' 항목에 있어 공개 시점은 주의 필요 |
| 북카페 | 불참 이유, 독서 경험 부족, 모임 대신 대화 | 질문에 답하고 부담을 줄이는 설명, 가벼운 대화 선택 반영. 불참 이유에 원문 밖 부연이 섞이는 한계도 관찰 |

## 결말 확인

다섯 팩 모두 독립 마지막 장면 검사에서 `ended=true`, 결말 제목, 세션 삭제를 확인했다.

| 팩 | 선택 | 반환된 결말 |
| --- | --- | --- |
| 베네치아 | 친구로 연락 | 오래된 친구의 새 연락처 |
| 교토 | 사진 친구 | 서로의 여행 한 장 |
| 제주 | 친구로 연락 | 바람이 전하는 안부 |
| 라디오 | 사적인 데이트 | 주파수 밖의 만남 |
| 북카페 | 다음 데이트 | 함께 쓰는 다음 페이지 |

화면의 `CHAPTER 04 / 04`만으로는 종료가 아니다. 서버가 조건과 결말을 검증한 뒤 `ended=true`를 보내면 화면에 `♥ THE END ♥`와 결말 제목이 나타나고 입력이 비활성화된다.

## 교토 최종 재검사

[최종 결과](qa/kyoto-final-verified.json)에서 ‘강변에서 한 장씩 찍으실래요?’에 ‘좋아요’라고 답했을 때 3장으로 이동했다. 다음 응답에는 함께 걷자는 반응과 함께, 사진을 잘 찍어야 한다는 부담 때문에 즐거움을 잃었다는 구체적 고민 설명이 포함되었고 그 뒤 의견을 물었다. `ended=false`로 중간 장면이 결말로 오인되지 않은 것도 확인했다.

그 전 검사에서는 낮은 추론뿐 아니라 기본 추론에서도 같은 동행 질문을 다시 묻는 사례가 있었다. 수정 요청의 미완료 값을 확정 사실로 취급하지 않게 하고, 직전 구체적 제안에 대한 짧은 동의의 의미를 명시한 뒤 위 사례가 통과했다. 한 사례의 통과가 모든 자연어 표현의 정확성을 보장하지는 않는다.
